# Lista de Tarefas em Python 

Projeto simples desenvolvido em Python para gerenciamento de tarefas no terminal.

##  Funcionalidades
- Adicionar tarefas
- Listar tarefas cadastradas
- Remover tarefas
- Menu interativo no terminal

##  Tecnologias utilizadas
- Python

##  Como executar

1. Instale o Python no seu computador
2. Baixe o arquivo `lista_tarefas.py`
3. Execute no terminal:

python lista_tarefas.py

##  Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação, uso de listas e interação com o usuário no terminal.
